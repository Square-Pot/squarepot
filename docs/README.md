# Documentation

Design documents come before code. All of them are drafts until the product
owner approves them.

- [Requirements](requirements.md): goals, users, scope of the first public
  release, quality targets, what is out of scope, and the product owner's
  decisions.
- [Spreadsheet format](sheet-format.md): the contract between a collection's
  Google Sheet and Square-Pot.
- [Field schema](../schema/fields.yaml): the single definition of plant fields,
  display rules and default presets.
- [Architecture decision records](adr/): why the main decisions were made.

The self-hosting guide will be added together with the deployment.
